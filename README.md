# KiukMaster 블로그

## 글 발행하기

1. `posts/<slug>/index.html`에 글 본문을 작성합니다. `<body data-slug="...">`의 값은 폴더 이름과 같아야 합니다.
2. `data/posts.json`의 `posts` 배열에 글 정보를 추가합니다. 새 글에는 한국 시간 기준 작성 시각 `time`을 꼭 입력하세요.

```json
{
  "slug": "new-post",
  "title": "새 글 제목",
  "excerpt": "글 요약",
  "date": "2026-09-25",
  "time": "18:30",
  "type": "post",
  "category": "",
  "tags": []
}
```

`date`는 `YYYY-MM-DD`, `time`은 24시간제 `HH:mm` 형식입니다. 목록의 최신순과 오래된순, 글 아래 이전·다음 링크는 이 날짜와 시각을 기준으로 정렬됩니다. 최신 글이 홈의 첫 카드에 표시되며, 오래된 추천 글도 그보다 앞에 고정되지 않습니다.

기존 글처럼 `time`이 없으면 정렬할 때 `00:00`으로 간주합니다. 날짜와 시각이 모두 같을 때는 `posts.json`에서 뒤에 적힌 글이 최신순에서 먼저 나옵니다. 정확한 순서를 위해 새 글마다 실제 시각을 입력하세요. 글 HTML의 `article:published_time` 메타 태그도 같은 한국 시간으로 맞춰 주세요. 예: `2026-09-25T18:30:00+09:00`.

## 대구 울산 경북지역 SW 중심대학 교육 Google Cloud AI Agent Challenge {#section-one}

일시 : 2026년 4월 25일 ~ 5월 30일 매주 토요일

평소 친하게 지내던 학교 선배, 동기들과 이번 프로그램에 참여하게 되었습니다!

## 진행 {#section-two}

이번 프로그램은 구글 생태계 기반 실무형 AI Agent 개발자 양성을 목적으로 하고 있습니다.

GCP(구글 클라우드 플랫폼)과 Python 기초, 구글의 Antigravity 등의 기초적인 부분의 수업이 상당히 도움 되었다고 생각합니다!

이번 프로그램의 경우 온라인으로 약 5주간 매주 토요일 강의를 진행 하였고, 해당 강의를 모두 시청하면 Google Cloud 공인 교육센터 인증 수료증을 발급 하더군요.

## 결론 {#section-three}

비록 본선에 진출하지는 못했지만, 수준 높은 강의를 들을 수 있어서 이번 강의를 들어본 것 만으로 좋은 경험이 되었다고 생각합니다.
